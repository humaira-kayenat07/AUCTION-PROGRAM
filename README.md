# Auction Program — Blind Bidding & Winner Selection System

## Project Overview
The Auction Program is a Python-based project that collects bids from participants and identifies the highest bidder as the winner. It demonstrates the use of basic Python programming concepts, including loops, conditional statements, dictionaries, and user input.

## Features
- Accepts participant names and bid amounts.
- Stores bids using a Python dictionary.
- Compares bid amounts to identify the highest bidder.
- Displays the auction results and announces the winner.

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed on your system.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python Auction_program.py
```

5. Enter the participant names and bid amounts when prompted.

## Sample Output
For example, if Bob places the highest bid of $5000, the program announces Bob as the winner.

## Concepts Demonstrated
- Variables and user input

- `while` and `for` loops
- `if-else` conditional statements
- Comparing values
